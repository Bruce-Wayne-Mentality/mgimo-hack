# GigaChat: эмбеддинги — что известно и откуда

Метки: **подтверждено документацией** — прочитано на developers.sber.ru 17.11.2026; **проверено вызовом** — получено запросом с ключом проекта на сервере; **предположение** — ни тем, ни другим не подтверждено.

## Метод и формат

| Факт | Статус |
| --- | --- |
| Метод `POST {GIGACHAT_API_URL}/embeddings` (в проекте `https://api.giga.chat/v1/embeddings`), тело `{"model": …, "input": [строки]}` | подтверждено документацией (руководство «Векторное представление текста») |
| В ответе `data[]` с полями `embedding` и `index`; `index` соответствует позиции строки в `input` | подтверждено документацией (описание метода «Создать эмбеддинг») |
| Модель по умолчанию — `Embeddings` | подтверждено документацией |
| Для `EmbeddingsGigaR` к **запросу** (не к документам) рекомендуется добавлять инструкцию на естественном языке | подтверждено документацией |
| Авторизация — тот же OAuth-токен, что и для чата | проверено вызовом: OAuth прошёл, ответ метода — 402, а не 401 |

## Модели

| Модель | Контекст | Размерность | Статус |
| --- | --- | --- | --- |
| `Embeddings` | 512 токенов | 1024 | подтверждено документацией |
| `EmbeddingsGigaR` | 4096 токенов | 2560 | подтверждено документацией |
| `Embeddings-2`, `GigaEmbeddings-3B-2025-09` | не указаны на страницах моделей | не указаны | подтверждено документацией только существование |

Цена у всех моделей эмбеддингов — 14 ₽ за 1 млн токенов, одинаково для физических и юридических лиц: подтверждено документацией (страницы моделей).

## Лимиты

| Факт | Статус |
| --- | --- |
| Максимальное число строк в одном запросе | **не найдено** в документации; в клиенте батчи по 16 строк (`EMBED_BATCH`) — предположение, безопасное значение |
| Длина строки ограничена контекстом модели (512 токенов у `Embeddings`) | подтверждено документацией; поведение при превышении (обрезка или ошибка) — не проверено, т. к. см. ниже |
| Один поток на ключ Freemium | уже учтено в клиенте (`Semaphore(1)`), общий для чата, «Красной кнопки» и эмбеддингов |

## Результат пробных вызовов (сервер, 17.11.2026)

`gigachat-probe` и прямые вызовы для `Embeddings`, `EmbeddingsGigaR`, `Embeddings-2`, на строках из 50, 300 и 600 слов и на пакете из 40 строк: **все вернули HTTP 402 (Payment Required)** — проверено вызовом. Чат-модель `GigaChat-2` по тому же ключу отвечает (на ней работает этап 2 «Красной кнопки»).

Вывод: у ключа проекта нет оплаченного пакета эмбеддингов. Размерность вектора и реальные лимиты длины **вызовом не проверены**; цифры выше — из документации.

Что это значит для RAG:
- клиент обрабатывает 402 как `GigaChatUnavailable` — исключение не выходит наружу;
- поиск работает в режиме `bm25_only`, ответ — дословный фрагмент с источником (правило 5);
- векторный и гибридный режимы в оценке (шаг 7) помечаются «не измерено»;
- после покупки пакета эмбеддингов в личном кабинете GigaChat достаточно выполнить `kb-embed` — правок кода не нужно.

Без ключа (`GIGACHAT_CREDENTIALS` пуст) `python -m hse_schedule.cli gigachat-probe` печатает «Ключ не задан» и завершается с кодом 0 — проверено запуском локально.
