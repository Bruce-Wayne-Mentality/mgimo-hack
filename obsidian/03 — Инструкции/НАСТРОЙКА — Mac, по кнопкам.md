# НАСТРОЙКА — Mac, по кнопкам

> Руководство актуализировано для интерфейса Obsidian на ноябрь 2026. Названия кнопок могут отличаться при русской локализации. **Не создавайте новый пустой vault поверх готового архива.**

## Шаг 0. Что внутри

Вы получили готовую папку `Цифровой_деканат_Рабочая_система`, в ней уже находятся:

- `00 — ДАШБОРД.md` — главный экран;
- `02 — Дорожная карта.canvas` — интерактивная визуальная карта этапов;
- `03 — Карта системы.canvas` — карта модулей;
- `01 — Разработка/Модули/*.md` — задачи по C1–C5, S1, K1–K12;
- `01 — Разработка/Вехи.md` — контрольные точки;
- `02 — Управление/02 — План по дням.md` — календарь и разделение на A/B;
- `Разделы/` и `Диздок — полный текст.md` — исходный полный диздок;
- `Вложения/` — схема архитектуры и PDF.

Плагины **не устанавливаются автоматически** с ZIP. Сначала распакуйте папку и откройте её как Vault.

## Шаг 1. Открыть готовое хранилище

1. В Finder дважды нажмите на загруженный ZIP, чтобы распаковать.
2. Переместите распакованную папку `Цифровой_деканат_Рабочая_система` в удобное место (например, `Documents`).
3. Откройте **Obsidian**.
4. В нижнем левом углу нажмите значок **Vault profile / профиль хранилища** (иногда стрелки рядом с названием vault).
5. Нажмите **Manage vaults… / Управление хранилищами…**.
6. В блоке **Open folder as vault / Открыть папку как хранилище** нажмите **Open / Открыть**.
7. В Finder выберите **саму распакованную папку**, а не `Разделы` и не `Вложения`.
8. Нажмите **Open**. В левом дереве файлов появится `00 — ДАШБОРД`.
9. Если старый Obsidian спросит разрешение на открытие vault с настройками — проверьте, что выбрали нужную папку.

**Альтернативный вход:** `Cmd + P` → найдите `Open another vault` → откройте список vault и повторите пункты 5–8.

## Шаг 2. Проверить версию и включить встроенные плагины

1. Внизу слева нажмите **Settings (шестерёнка)**.
2. Слева — **General / Общие** → посмотрите **Obsidian version**. Для Gantt Calendar нужна версия **1.13.0+**; обновите Obsidian, если приложение старее.
3. В левом меню нажмите **Core plugins / Основные плагины**.
4. В строке поиска напишите `Canvas` и убедитесь, что тумблер включён.
5. Так же проверьте `Command palette` (палитра команд).
6. Закройте настройки кнопкой `×` в правом верхнем углу.
7. В левом дереве файлов нажмите `02 — Дорожная карта.canvas`; должна открыться карта с карточками.

**Важно:** на Mac палитра команд открывается `⌘ Cmd + P` (не `Ctrl+P`).

## Шаг 3. Установить Tasks

1. **Settings** → **Community plugins / Сторонние плагины**.
2. Если видите **Restricted mode / Ограниченный режим**, нажмите **Turn on community plugins / Включить сторонние плагины**. Учтите, что сторонние плагины имеют доступ к файлам vault; устанавливайте только те, которым доверяете.
3. Нажмите **Browse / Обзор**.
4. В поле поиска введите **Tasks**. Выберите плагин **Tasks** от obsidian-tasks-group.
5. Нажмите **Install / Установить**, затем **Enable / Включить**.
6. Закройте окно магазина и откройте `00 — ДАШБОРД.md`.
7. Переключите заметку в **Reading view / Режим чтения** через меню `⋯` вкладки, если вместо списков видите код `tasks`.
8. Проверьте, что раздел **«Просрочено и на сегодня»** показывает задачи с чекбоксами.

Если блок показывает текст `No tasks found`, проверьте, что открыли **готовую папку**, в которой есть `01 — Разработка/Модули` и соответствующие задачи.

## Шаг 4. Установить Tasks Kanban и открыть доску

1. **Settings → Community plugins → Browse**.
2. Поиск: **Tasks Kanban** (не просто `Kanban`). Выберите плагин Julien Tanay.
3. Нажмите **Install**, затем **Enable**. Плагин **Tasks** тоже должен оставаться включённым.
4. Закройте настройки. Нажмите **Cmd + P**.
5. В поиске палитры команд напишите **Tasks Kanban**.
6. Выберите **Tasks Kanban: Open board** (в отдельных сборках команда может отображаться без префикса, как `Open board`).
7. В открывшейся вкладке найдите **Filter / значок фильтра** (или редактор query) и вставьте строку:

   `tag includes #dekanat`

8. В качестве сортировки укажите `sort by due`, если плагин предлагает редактор query.
9. Проверьте, что появились задачи из модулей.
10. Перетащите **одну** тестовую задачу из `Todo` в `In Progress`, затем откройте её исходный файл: маркер задачи должен измениться с `- [ ]` на `- [/]`. После проверки верните назад, если реально работу не начинали.
11. При желании в **Settings → Tasks Kanban** создайте Saved board с названием `Цифровой деканат` и тем же фильтром. Дальше открывайте `Open saved query…`.

**Колонки по умолчанию:** Todo / In Progress / Done / Cancelled. Кастомные статусы внутри Tasks поддерживаются, но для первого запуска их менять не нужно.

## Шаг 5. Установить Gantt Calendar и увидеть интерактивный Roadmap

1. **Settings → Community plugins → Browse**.
2. Введите **Gantt Calendar** (плагин `sustcsugar`).
3. Нажмите **Install → Enable**.
4. `Cmd + P` → **Gantt Calendar: Open Calendar View**.
5. В левой части верхней панели плагина найдите **переключатель вида** (Month / Week / Task / Gantt) и выберите **Gantt**.
6. Нажмите **Filter**, выберите фильтрацию по тегам и укажите **`#roadmap`**, чтобы видеть только большие модули и вехи; при необходимости можно поставить `#dekanat`, чтобы увидеть все задачи.
7. Если шкала показывает не те даты, откройте **Settings → Gantt Calendar → Views → Gantt**. Установите начало по **Start date**, конец по **Due date**.
8. Для проверки переместите тестовую полоску задачи на один день. Перейдите в её Markdown-файл и проверьте, что `🛫 YYYY-MM-DD` / `📅 YYYY-MM-DD` изменились. Верните обратно.
9. Пункты **K9–K12** не имеют назначенной даты, поэтому на Gantt они не отображаются; они остаются в Kanban / списке модулей, пока вы не назначите даты.

**Разница между картами:** `02 — Дорожная карта.canvas` — свободная визуальная карта, а Gantt Calendar — календарь с настоящими редактируемыми датами.

## Шаг 6 (необязательно). Поставить Dataview для числового прогресса

1. **Settings → Community plugins → Browse**.
2. Найдите `Dataview` → **Install → Enable**.
3. **Settings → Dataview** → включите **Enable JavaScript Queries**.
4. Откройте `00 — ДАШБОРД.md` в **Reading view**.
5. В разделе «Сводка выполнения» должна появиться таблица `Все задачи / P0 / P1 / P2 / Roadmap` с числом сделанных задач и процентом.

Этот блок только читает чекбоксы задач. Если Dataview не установлен, Kanban и Gantt продолжают работать.

## Шаг 7 (необязательно). Включить стиль dashboard

1. **Settings → Appearance / Оформление → CSS snippets**.
2. Нажмите значок **круговой стрелки (Reload snippets)**, чтобы увидеть `dekanat-dashboard`.
3. Включите тумблер `dekanat-dashboard`.
4. Вернитесь к `00 — ДАШБОРД.md`.

Стиль меняет только внешний вид и не нужен для функциональности.

## Шаг 8. Как работать каждый день

1. Откройте `00 — ДАШБОРД.md`.
2. Просмотрите `Просрочено и на сегодня`.
3. Откройте **Tasks Kanban** и перетащите выбранные задачи в `In Progress`. Это изменит их статусы в оригинальном Markdown.
4. Откройте **Gantt Calendar → Gantt**, сдвиньте даты задач, по которым возникло отставание.
5. Через `02 — Дорожная карта.canvas` откройте заметку конкретного модуля, проверьте требования и задачи.
6. Когда выполнены и проверены все мелкие задачи модуля, закройте его верхний чекбокс `Модуль полностью готов`.
7. Запишите блокирующие проблемы в `02 — Управление/Риски и открытые решения.md`.
8. Вечером проверьте `01 — Разработка/Вехи.md` и реальный результат дня.

## Быстрые ответы на сбои

| Симптом | Что нажать / проверить |
|---|---|
| `Tasks` блок — просто код | Включить Tasks, открыть Reading view |
| Нет команды `Tasks Kanban` | `Settings → Community plugins → Installed plugins → Tasks Kanban → Enable` и Tasks тоже |
| Нет Gantt / пустой Gantt | Проверить версию 1.13+, `Cmd + P → Gantt Calendar: Open Calendar View`, даты `🛫`/`📅`, фильтр и вид `Gantt` |
| Canvas — пусто | Открыть готовый `02 — Дорожная карта.canvas`, включить Core plugin Canvas |
| Даты неправильные | `Settings → Gantt Calendar → Views → Gantt`; проверить локальный часовой пояс и фильтры |
| DataviewJS показывает код | `Settings → Dataview → Enable JavaScript Queries`, Reading view |
| В карточке одно и то же два раза | Не копировать задачу в новый файл — меняйте её в одном месте, исходной заметке |
| Не виден Dashboard | `Cmd + O`, напечатать `00 — ДАШБОРД`, Enter |
| После разархивирования не видны папки | Открыли папку уровнем выше/ниже — используйте `Manage vaults → Open folder as vault` |

## Опционально: Meta Bind

**Meta Bind** полезен для кнопок и редактируемых полей в заметках, но здесь не нужен для задач. Его toggle в YAML **не связан** автоматически с Tasks-чекбоксами. Чтобы избежать двух противоречивых статусов, сначала используйте Tasks и Gantt. Meta Bind включайте позже только для отдельных настроек проекта.

## Проверка результата

- [ ] В Obsidian открыт `00 — ДАШБОРД.md`.
- [ ] В `02 — Дорожная карта.canvas` открываются заметки модулей.
- [ ] В Dashboard виден живой список Tasks.
- [ ] В Tasks Kanban видны колонки и карточки.
- [ ] В Gantt Calendar видны полосы модулей/вех по датам.
- [ ] Перенос карточки обновляет Markdown-задачу.
- [ ] Перенос Gantt-полосы обновляет даты `🛫`/`📅`.
- [ ] Установлены реальные владельцы A/B и уточнён конкурсный дедлайн.
