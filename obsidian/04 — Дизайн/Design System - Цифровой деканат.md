# Design System — Цифровой деканат (Soft Blue)

> [!warning] Что берём из референса, а что нет
> Переносим **визуальный язык**: палитру, типографику, сетку, формы карточек, поведение элементов. **Не переносим** чужие ассеты: фото интерьеров, 3D-рендеры, маскота-домик, бренд «Kaiwa» и тексты кейса. Вместо них — свои иллюстрации/CSS-моки и контент «Цифрового деканата». Значения ниже сняты на глаз со скриншотов (JPEG/WebP), это оценка, а не исходники макета.

## 1. Концепция и настроение

- **«Мягкий синий».** Светлый холодный фон, белые карточки, один насыщенный королевский синий как бренд-цвет. Ощущение спокойного, «домашнего» сервиса, без агрессии.
- **Карточки поверх контекста.** Ключевой приём — белые «виджеты» со скруглением 24px, которые лежат поверх фото/иллюстрации или синего блока и показывают живые данные (температура 21°C, влажность 37%, «Состояние: Отлично ✓»). Для нас: «Следующая пара 10:40 · ауд. 305», «Заявка: в работе», «Светофор: всё в порядке».
- **Бенто-сетка.** Секции собираются из плиток разного размера (1×1, 2×1, 1×2) с одинаковым зазором.
- **Крупная лёгкая типографика.** Заголовки большие (48–72px), но тонкие (400), с плотным трекингом. Иерархию даёт размер, а не жирность.
- **Синий как сцена.** Целые секции заливаются брендовым синим; на нём — белые карточки, пунктирные линии-связи и огромный полупрозрачный водяной знак-слово.
- **Тени почти нет**, разделение — фоном и мягкой тенью с синим оттенком; стекло (blur) только у виджетов поверх фото.

## 3. Типографика

**Шрифт:** Onest (Google Fonts, есть кириллица, веса 300–700). Ближайшая бесплатная замена гротеску из макета: геометричный, открытые формы, ровные цифры. Один шрифт на всё, моноширинный не используется.

| Роль | Размер / интерлиньяж | Вес | Трекинг | Пример |
|---|---|---|---|---|
| Display XL | 72 / 1.04 | 400 | −0.035em | заголовок героя |
| Display L | 48 / 1.08 | 400 | −0.03em | заголовок секции |
| H1 | 40 / 1.1 | 500 | −0.025em | заголовок экрана в кабинете |
| H2 | 32 / 1.15 | 500 | −0.02em | «Сценарии», «Режимы» крупно |
| H3 | 24 / 1.2 | 500 | −0.015em | заголовки карточек-витрин |
| Title | 18 / 1.3 | 500 | 0 | «Настольная лампа», «Комнаты» |
| Body | 16 / 1.5 | 400 | 0 | абзацы |
| Small | 14 / 1.45 | 400 | 0 | текст чипов, кнопки 2-го уровня |
| Caption | 12 / 1.35 | 400 | 0 | подписи под значениями, цвет `--k-muted` |
| Stat | 44 / 1 | 500 | −0.02em | «30%», «24/7», «>80%», «21°C» |

- Мобайл: Display XL → 40/1.08, Display L → 32/1.12, H1 → 28.
- Заголовки — sentence case, без капса. Акцентное слово можно выделить синей «плашкой» (`bg-k-primary`, белый текст, `radius 8px`, отступ 0 8px) — как «в 1 клик».
- Цифры с единицами пишем с узким отступом: `21°C`, `37%`, `00:04:32`.

## 4. Скругления, тени, блюр

| Токен | px | Где |
|---|---|---|
| `--k-r-xs` | 8 | маленькие квадратные кнопки-стрелки 28–32px |
| `--k-r-sm` | 12 | кнопки, инпуты, чипы-сценарии |
| `--k-r-md` | 16 | плитки внутри карточек |
| `--k-r-lg` | 24 | карточки, виджеты |
| `--k-r-xl` | 32 | контейнеры секций, рамка телефона |
| `--k-r-pill` | 999 | переключатели, пилюли «Live», ярлыки |

- **Карточка:** `--k-shadow-card` = `0 1px 2px rgb(18 24 38/.04), 0 8px 24px rgb(47 106 230/.06)` — почти невидимая, с синим оттенком.
- **Плавающий виджет над фото:** `--k-shadow-float` = `0 12px 32px rgb(18 24 38/.12)` + `background: var(--k-glass); backdrop-filter: blur(16px)`.
- **Фокус:** `--k-focus-ring` = `0 0 0 3px rgb(47 106 230/.28)`.
- Обводки почти не используются; исключение — выбранный чип (`1px solid --k-primary`).

## 5. Сетка, отступы, брейкпоинты

- Шаг **4px**. Шкала: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 · 80 · 120.
- Контейнер **1200px**, поля 24px (16px на мобильном). 12 колонок, зазор 16px; в бенто-плитках — 12–16px.
- Вертикальный ритм секций: 80–120px на десктопе, 48–64px на мобильном. Внутри карточки — паддинг 20–24px (16px на мобильном).
- Секции лендинга — «острова»: контейнер `--k-r-xl` со своим фоном и отступом 12–16px от соседних.
- Брейкпоинты: **390** (телефон) · **768** (планшет: бенто 2 колонки) · **1024** (сайдбар) · **1280** · **1440** (десктоп, контейнер 1200).

## 6. Компоненты

### Кнопки
| Вариант | Вид | Состояния |
|---|---|---|
| Primary | `bg --k-primary`, белый текст 16/500, `h 48–52`, `radius 12`, ширина по контенту или 100% в формах | hover `--k-primary-600`; active — сдвиг на 1px вниз; disabled 50% |
| Secondary | `bg --k-primary-50`, текст `--k-primary-700` | hover `--k-primary-100` |
| На синем | `bg #fff`, текст `--k-primary` | hover `--k-primary-50` |
| Иконка-стрелка | квадрат 28–32px, `radius 8`, синий фон + белая `→` (или `--k-surface-2` + синяя стрелка) | hover — стрелка смещается на 2px вправо |
| Ссылка-действие | текст `--k-primary` 14/500 + `›` («Все сценарии ›», «Все ›») | hover — подчёркивание |

### Инпуты
- Белые, без рамки, `h 52`, `radius 12`, паддинг 0 16px, плейсхолдер `--k-muted` 16/400.
- На светлом фоне — чистый белый; на белом — `--k-surface-2`.
- Фокус: `--k-focus-ring`. Ошибка: красная подпись 12px под полем + иконка.

### Карточки
- **Базовая:** белая, `radius 24`, паддинг 20–24, `--k-shadow-card`. Заголовок Title + справа действие (переключатель/«Все ›»).
- **Синяя инфо-карточка** («Гостиная, 21°C, 37%»): `--k-primary`, белый текст, крупные значения 24/500 и подписи 12px с прозрачностью 0.8.
- **Стат-карточка:** белая, значение Stat + подпись Small `--k-text-2`, висит поверх иллюстрации на «булавке» (точка + тонкая линия).
- **Плитка-витрина** («Освещение», «Безопасность»): `--k-bg-2`, `radius 24`, заголовок H3 синим `--k-primary` сверху слева, изображение прижато к низу/краю, кнопка-стрелка в правом нижнем углу.
- **Шаг процесса**: белая карточка `radius 16`, номер в пилюле `01` (`--k-primary-50`, 12px), заголовок Title, описание Small, иллюстрация справа; шаги соединены пунктиром `--k-on-blue-line`.

### Чипы и переключатели
- Чип-сценарий: `--k-surface` на тинте / `--k-surface-2` на белом, `radius 12`, `h 44`, иконка 20px в квадрате `--k-primary-50` + текст 14px. Выбранный: обводка 1px `--k-primary`.
- Чип-фильтр времени («2ч 4ч 8ч»): `h 36`, `radius 10`, выбранный — обводка `--k-primary`.
- Переключатель: 44×24, `pill`, вкл — `--k-primary` с белым кругом справа.
- Ярлык «Live»: белая пилюля, красная точка 6px + текст 12/500.

### Индикаторы данных
- Горизонтальные шкалы `h 40`, `radius 12`: температура — градиент `--k-heat` с белой вертикальной меткой текущего значения; влажность — заполнение `--k-humidity` на `--k-primary-50`.
- Круговые дуги (таймер/яркость): трек `--k-primary-100` 10px, заполнение `--k-primary`, ручка — белый круг с синей иконкой.

## 7. Поведение и анимации

- **Принцип:** движение мягкое и короткое, объясняет изменение, а не украшает.
- `--k-ease` = `cubic-bezier(.22,1,.36,1)`; `--k-dur-fast` 160ms (цвет, переключатели), `--k-dur` 240ms (кнопки, чипы), `--k-dur-reveal` 520ms.
- **Hover:** карточки-витрины — подъём фона на тон (`--k-bg-2` → `--k-primary-100`) и сдвиг стрелки на 2px; кнопки — смена фона; без масштабирования и «прыжков» карточек.
- **Появление при скролле:** fade + подъём на 16px, задержка между плитками 60ms, один раз. Библиотека — `motion` (бывший Framer Motion).
- **Данные:** значения (`21°C`, проценты) анимируются счётчиком 400ms при первом показе; шкалы заполняются слева направо.
- `prefers-reduced-motion`: все переходы мгновенные, появление без движения.

## 8. Как система применена в кабинете

Стиль применяется к **существующим и будущим экранам кабинета** (не к лендингу). Компоненты — `apps/web/src/components/ui/index.tsx`, каркас — `apps/web/src/app/AppShell.tsx`.

| Экран | Что взято из референса |
|---|---|
| Каркас (десктоп ≥768) | Плавающий белый сайдбар-карточка 104px, `radius 24`, отступ 12px от краёв: логотип в синем квадрате сверху, пункты «иконка над подписью», активный — `--k-primary-50` + синий текст, профиль (круглый аватар) внизу. Точка `--k-danger` на «Уведомлениях» при непрочитанных. |
| Каркас (мобайл <768) | Шапка на стекле (`bg/80 + blur 16`), круглые кнопки колокольчика и аватара; плавающий таб-бар `radius 22`, `--k-shadow-float`, отступ 12px + safe-area, активный пункт синий. |
| Вход `/login` | Слева синяя плита `--k-gradient-primary` с водяным знаком «деканат», заголовком 52–60/400 и плавающими виджетами («Следующая пара 10:40», «Всё в порядке ✓»); справа белая карточка формы, инпуты `--k-surface-2` без рамки, синяя кнопка во всю ширину, тестовые аккаунты — плитки с синей кнопкой-стрелкой. |
| Главная `/` | «Анна, привет!» 40/400 + серая подпись; ряд статус-плиток (иконка в чипе · подпись · значение + ✓/точка) как «Состояние дома»; карточка «Сегодня» с синим блоком «Следующая пара» (как синяя карточка комнаты) и плитками пар; карточка «Уведомления» со ссылкой «Все ›». |
| Расписание `/schedule` | Карточка фильтра с инпутами-датами; карточки дней, в них плитки пар `--k-surface-2` с временем в синем чипе. |
| Уведомления `/notifications` | Непрочитанные — плитки `--k-primary-50` с синей точкой, прочитанные — `--k-surface-2`; счётчик в синей пилюле; каналы — плитки с иконкой-чипом и переключателем-пилюлей. |
| Профиль `/profile` | Синяя «карта студента» с аватаром и пилюлями (группа, курс, статус); данные — сетка плиток «подпись / значение»; смена пароля и выход — две карточки рядом. |
| Ещё, заглушки | Список плиток с иконкой в чипе и стрелкой, которая сдвигается при наведении. |

### Утилиты, добавленные в `styles.css`
- `.caption` — серая подпись 13/1.35.
- `.soft` — мягкая смена цвета/фона/тени 160ms + сдвиг на 1px при нажатии (без подъёма и масштабирования).
- `.nudge` — стрелка внутри действия сдвигается на 2px при наведении.

### Шаблон нового экрана
1. `PageHeader` (серый eyebrow + заголовок 40/400).
2. Сетка карточек `Card` с зазором 16px; внутри — плитки `--k-surface-2` `radius 16`.
3. Действие карточки — `MoreLink` («Все ›») или `Switch` справа от `CardTitle`.
4. Один акцентный синий элемент на карточку (блок, кнопка или чип).
5. Состояния: `Skeleton` → данные / `EmptyState` / `ErrorState` с «Повторить».

## 9. Правила расширения

1. Новые цвета — только через токены `--k-*`, не хардкодить HEX в компонентах.
2. Новый тип карточки = белая основа `radius 24` + один акцент (синий заголовок, синяя кнопка или синяя плитка), не больше.
3. Иконки — Lucide, stroke 1.75, размеры 16/20/24; иконка в действии всегда в квадрате `--k-primary-50`.
4. Не добавлять: градиенты кроме двух задокументированных, тени темнее `.12`, обводки толще 1px, курсивы.
5. Любой экран проверять на 390 и 1440 и в `prefers-reduced-motion`.
