# 15. Тестирование, риски, открытые вопросы и сдача

### 15.1 Тесты

| Уровень | Инструмент | Что проверяем | Обязательно |
| --- | --- | --- | --- |
| Бэкенд | pytest + httpx | Переходы статусов заявок, формула светофора, правила брони, подпись документа | Да |
| Безопасность | pytest | Студент Б получает 404 на каждый объект студента А (профиль, заявка, документ, бронь, уведомление, ICS); студент не видит внутренние комментарии; неудачный вход блокируется после 5 попыток | Да |
| Бд | pytest на настоящей PostgreSQL | Два одновременных запроса на одно время аудитории дают одну бронь и одну ошибку | Да |
| Фронтенд | Vitest | Расчёты в интерфейсе (что если, даты), формы по схеме | По возможности |

| Уровень | Инструмент | Что проверяем | Обязательно |
| --- | --- | --- | --- |
| Сквозные | Playwright на 360×740 | Вход → расписание → оценки → заявка → статус → уведомление → выход; сценарий сотрудника | Да |
| Доступность | axe-core | Нет серьёзных нарушений на основных экранах | Да |
| ИИ | tests/assistant_cases.yaml | 30 вопросов, промпт-инъекции, поведение при недоступном GigaChat | Да |
| Нагрузка | k6 или locust | Вход и чтение расписания под нагрузкой жюри | День 13 |
| Ручные | человек | Проход демо-сценария из раздела 3 с настоящего телефона из российской мобильной сети | Да |

Правило для ИИ-ассистентов, пишущих код: проверять результат нельзя словами ассистента «готово». Функция считается готовой, если её тест зелёный и человек прошёл сценарий вручную.

### 15.4 Чек-лист сдачи

- Ссылка на прототип открывается с российской мобильной сети без VPN.

- Тестовые аккаунты (минимум два студента и сотрудник) работают; логины и пароли вписаны в комментарий к работе.

- Репозиторий открыт для жюри или архив лежит на Диске с доступом; в нём нет секретов.

- Описание процесса собрано в PDF или документ по ссылке: проблема и опрос однокурсников, полный перечень ИИ-инструментов и для чего каждый, ключевые промпты по этапам, скриншоты (включая неудачные), объяснение входа и защиты простыми словами, этапы, сделанные вручную.

- На сайте видно, что это концепт для конкурса, а не официальный сервис; официального логотипа нет.

- Все данные выдуманные, никаких ключей в коде и в браузере.

- Сторонние шрифты, иконки и изображения — только с разрешающей лицензией; список в LICENSES.md.

- Версия в личном кабинете конкурса — последняя; прототип работает до 28 ноября.
